# آرایشی بهداشتی بابک 💄 (نسخه بدون بیلد)

این نسخه کامل HTML/CSS/JS ساده‌ست، دقیقاً مثل سایت‌های قبلی‌تون — هیچ نیازی به نصب چیزی یا اجرای دستور «بیلد» نیست.
فقط فایل‌ها رو توی گیت‌هاب آپلود می‌کنید و گیت‌هاب پیجز رو فعال می‌کنید، همون کاری که بلدید.

فایل‌های پروژه:
```
index.html          صفحه اصلی فروشگاه
about.html           صفحه درباره ما
admin.html           پنل مدیریت
style.css            استایل مشترک صفحات فروشگاه
config.js             آدرس و کلید Supabase (باید پر کنید)
supabase-schema.sql   ساختار دیتابیس (فقط در Supabase اجرا می‌شود، آپلودش لازم نیست)
```

---

## مرحله ۱ — ساخت پروژه رایگان در Supabase

۱. به [supabase.com](https://supabase.com) بروید، ثبت‌نام کنید و یک پروژه جدید بسازید.
۲. از منوی سمت چپ وارد **SQL Editor** شوید، کل محتوای فایل `supabase-schema.sql` را کپی/پیست کرده و **Run** بزنید.
   این کار همه‌چیز (محصولات، دسته‌بندی‌ها، سفارش‌ها، تنظیمات، فهرست مدیران، فضای آپلود عکس) را می‌سازد.

### ساخت اولین مدیر
۱. از منو **Authentication → Users → Add user** — یک ایمیل و رمز عبور برای خودتان بسازید.
۲. دوباره به **SQL Editor** بروید و این خط را با ایمیل واقعی اجرا کنید:
   ```sql
   insert into public.admin_users (email) values ('admin@example.com');
   ```
   بدون این مرحله کسی نمی‌تواند وارد `admin.html` شود.

### برداشتن کلیدها
از **Project Settings → API**:
- **Project URL**
- **anon public key**

---

## مرحله ۲ — پر کردن فایل config.js

فایل `config.js` را باز کنید (با هر ویرایشگر متن ساده، حتی توی گوشی) و این دو خط را با مقادیر واقعی جایگزین کنید:

```js
const SUPABASE_URL = "YOUR_SUPABASE_URL";
const SUPABASE_ANON_KEY = "YOUR_SUPABASE_ANON_KEY";
```

---

## مرحله ۳ — آپلود روی گیت‌هاب و فعال‌سازی گیت‌هاب پیجز

۱. یک ریپازیتوری جدید بسازید (مثلاً `babak-shop`).
۲. تمام فایل‌های همین پوشه (`index.html`, `about.html`, `admin.html`, `style.css`, `config.js`) را داخلش آپلود کنید — `supabase-schema.sql` و `README.md` هم می‌توانید آپلود کنید یا نکنید، تاثیری روی سایت ندارند.
۳. از **Settings → Pages** گزینه‌ی Source را روی شاخه `main` (پوشه `/root`) بگذارید.
۴. چند دقیقه صبر کنید، لینک سایت آماده می‌شود، چیزی شبیه:
   `https://USERNAME.github.io/babak-shop/`

آدرس ورود پنل مدیریت: همون لینک + `/admin.html`

## راهنمای استفاده از پنل مدیریت

- **محصولات**: افزودن/ویرایش/حذف با عکس، نام، توضیحات، قیمت، قیمت با تخفیف، دسته‌بندی و لینک ترب.
- **دسته‌بندی‌ها**: می‌سازید و در منوی همبرگری و صفحه اصلی نمایش داده می‌شود.
- **سفارش‌ها**: سفارش‌هایی که مشتری از دکمه «ثبت سفارش» ثبت می‌کند.
- **مدیران**: افزودن/حذف ایمیل افرادی که اجازه ورود به پنل را دارند.
- **تنظیمات**: متن «درباره ما»، ایمیل شکایات و پیشنهادات، متن پایین سایت.

### نکته دکمه «خرید از ترب»
تا وقتی لینک ترب برای یک محصول خالی باشد، دکمه در سایت کم‌رنگ و غیرفعال است. به محض پر کردن و ذخیره‌ی لینک در پنل، دکمه فعال و رنگی می‌شود.

ساخته شده توسط امیرحسین سرافراز.
